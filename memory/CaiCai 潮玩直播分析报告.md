### 2. 对对碰玩法 ⭐⭐⭐⭐⭐

**规则：** 买 2 只相同款式 → 可兑换 1 只新娃

**话术示例：**
- "躺位有同样的娃，选一个换新的"
- "后面是不是要对碰了"
- "拍两单都是对对碰"

**效果分析：**
- 促进复购（买 2 换 1）
- 增加游戏化体验
- 观众间产生交换需求（社交属性）
- 有人"两单都一样"→ 获得兑换资格，晒单刺激他人

**商业逻辑：**
```
单只价格：279 元
对对碰门槛：279 × 2 = 558 元
兑换后实际成本：558 元得 3 只 = 186 元/只
观众感知：占了便宜
实际效果：客单价提升 100%
```


**2. 质量疑虑重复出现**
```
"钻容易掉吗"出现 5+ 次
→ 说明疑虑未解决
```

**建议：**
- 现场测试（拉扯钻饰）

**3. 观众流失加速**
```
峰值 1246→最低 320（-74%）
→ 工作日午后自然回落
```

**建议：**
- 优化直播时段（周末/晚间）
- 中场抽奖挽留

**4. 主播疲劳**
```
直播 150 分钟+，边吃边播
→ 状态可能下滑
```

**建议：**
- 控制时长在 90 分钟内
